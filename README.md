# CIVIC AI — Smart Community Problem Solver

## 📌 About the Project

CIVIC AI is an AI-powered web application that helps citizens report civic problems such as garbage collection, water supply issues, damaged roads, drainage problems, and broken streetlights.

It helps authorities manage complaints, prioritize urgent issues, and track their resolution.

## 🎯 Key Features

* **Submit Complaints:** Report civic issues with descriptions and locations.
* **AI Complaint Analysis:** Categorize complaints and suggest priority levels.
* **Track Complaints:** Check complaint status using a unique complaint ID.
* **Admin Dashboard:** View, filter, and manage complaints.
* **Status Updates:** Track Pending, In Progress, and Resolved complaints.
* **Persistent Storage:** Save complaints using server-side JSON storage.
* **Demo Data:** Includes six sample complaints for hackathon demonstrations.

## 🛠️ Technologies Used

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js
* Storage: JSON file
* AI: AI-powered complaint analysis, where configured

## 🚀 How to Run

1. Clone or download the project.
2. Open the project folder in your code editor.
3. Install the required dependencies:

   ```bash
   npm install
   ```
4. Start the application using the command specified in `package.json`.
5. Open the local URL displayed in the terminal.
